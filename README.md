## About the project

UrbanPulse analyses urban public-transport and mobility data to surface where
transit service is falling short and which communities are underserved.
The work combines raw data collection, cleaning, KPI modelling, and interactive
Power BI / Tableau dashboards.

**Cities studied:** Bangalore, Vizag (Visakhapatnam)

## Repository structure

Every milestone folder has the same five sub-folders, so you always know
where to look:

```
UrbanPulse-Infosys-Internship/
├── README.md                  <- you are here
├── CONTRIBUTING.md            <- how the team should add files
├── .gitignore
├── assets/screenshots/        <- images used in this README
│
├── Milestone-1/
│   ├── README.md              <- what this milestone was about
│   ├── data/                  <- datasets (.csv, .xlsx)
│   ├── code/                  <- cleaning & analysis (.py, .ipynb)
│   ├── dashboard/             <- .pbix / .twbx + screenshots
│   ├── presentation/          <- the PPT you presented (.pptx / .pdf)

│
```

## How to open the dashboards

1. **Power BI (`.pbix`)** — install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free), then double-click the file.
2. **Tableau (`.twbx`)** — install [Tableau Public](https://public.tableau.com/) (free), then open the file.

If you just want to *see* the dashboards without installing anything, look at
the `.png` screenshots inside each `dashboard/` folder.
